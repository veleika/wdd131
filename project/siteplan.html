Discover Tonga

Website Planning Document

WDD131 W05 Project | Created by Liekina Veleika

1. Site Name

Discover Tonga

Logo/Brand Name: Discover Tonga

I chose the name Discover Tonga because the purpose of the website is to help visitors discover the beauty, culture, traditions, food, history, beaches, and activities of Tonga. The name is simple, memorable, and directly represents the subject of the website.

Suggested domain: discovertonga.org

2. Site Purpose

The purpose of Discover Tonga is to provide useful and interesting information about Tonga and its islands. The website will introduce visitors to Tongan culture, traditional food, beaches, history, community life, and activities that can be experienced in Tonga.

The website will provide information and visual content that helps visitors learn about Tonga and discover places and experiences they may want to explore. It will also provide a contact page where visitors can share their favorite Tongan place, food, activity, or cultural experience.

3. Scenarios

The following questions represent information that members of the target audience may want to find when visiting the website:

  • What are some beaches and island activities I can experience when visiting Tonga?
  • What traditional foods and cultural traditions can I learn about in Tonga?
  • What can I learn about Tongan history and community life?
  • How can I share my favorite Tongan place, food, or activity with the website?

4. Color Schema

The color scheme is inspired by the Pacific Ocean, the natural environment of Tonga, and warm tropical colors. These colors will be used throughout the website to create a consistent visual identity.

Primary Blue #003B5C Used for headers, navigation, headings, and footer.
Secondary Blue #005F73 Used for secondary headings, buttons, and accents.
Golden Accent #EE9B00 Used for highlights, borders, important accents, and calls to action.
Light Background #F4F7F8 Used as the main page background to improve readability.
Color usage: Text will use dark colors for readability. White will be used against the darker blue header and footer areas. The golden accent will be used sparingly to draw attention to important elements.

5. Typography

The website will use a simple, readable typography system. Arial is selected because it is clean, easy to read, and widely available across different devices.

Arial — Headings

Arial will be used for the main page headings, section headings, navigation, and important titles.

Arial — Body Text

Arial will also be used for paragraphs, descriptions, lists, forms, and other general website content.

Font family: Arial, Helvetica, sans-serif

Using one consistent font family will help keep the website readable and visually consistent on desktop and mobile devices.

Responsive design: On smaller screens, the navigation will use a menu button and content will be displayed in a single-column layout. On wider screens, the navigation and content will have more horizontal space and multiple content areas can appear side by side.

7. Development Plan

The final Discover Tonga website will use HTML for structure, CSS for responsive styling, and JavaScript for interactive features and dynamically generated content.

  • Home: Introduce Tonga and highlight major experiences.
  • Explore: Provide information about beaches, culture, food, activities, history, and community.
  • Contact: Allow visitors to submit their favorite Tongan place, food, activity, or experience.
  • References: List information and image sources used to create the website.
